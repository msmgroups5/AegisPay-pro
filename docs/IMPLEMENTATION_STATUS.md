Explicit non-production boundary:
This foundation does not perform real financial transfers, blockchain execution, custody, or external payment processing. It is a functional system-data demonstration aligned to the application specification.

Remaining external/deployment work:
A real production environment would still require separate backend/database/authentication infrastructure, secret management, external service credentials, domain/hosting configuration, security testing, operational monitoring and any applicable compliance/legal work.
